## 구현 완료 항목

### 1. 동료 AI / 수동 제어 전환 (`GameplayScreen.jsx`)
- 전투 패널 상단에 토글 버튼 추가: 🤖 AI / 🎮 수동
- `companionAutoMode` 상태 + `companionAutoModeRef` ref 이중 관리 (비동기 콜백 정확성)
- AI 모드: `triggerSubTurn` 내 동료 차례 시 500ms 후 `handleCompanionSubTurn` 자동 호출
- 수동 모드: `setPendingCompanionTurn(comp)` → 스킬 선택 패널 표시 → 사용자 선택 후 처리

### 2. NPC 서술 후 10초 카운트다운
- `startAdvanceCountdown()`: 1초 인터벌 타이머, `countdownSec` 카운트다운
- `handleAdvanceNow()`: 타이머 정리 후 즉시 `advanceSubTurn()` 호출
- `pendingAdvance` 상태: 카운트다운 중 "다음 (N초)" 버튼 표시
- `advanceTimerRef`: 중복 타이머 방지 및 컴포넌트 언마운트 정리

### 3. flatDamage 스킬 레벨 배율 수정
- 수정 전: `flatDamage` 고정 수치 적용
- 수정 후: `(skill.flatDamage ?? 0) * c.level` — 캐릭터 레벨에 비례
- 기공파 등 flatDamage 계열 스킬 모두 영향

### 4. saveCheck / onFailEffect 엔진 처리
- `jobs_levels.js`에 `saveCheck:{stat,dc}` + `onFailEffect:{type,turns,target}` 필드 추가
  - 주화입마 유도 (dh Lv3): `saveCheck:{stat:'WIS',dc:14}`, `onFailEffect:{type:'confused',turns:1}`
  - 봉혈 (us Lv3, jy Lv5): `saveCheck:{stat:'CON',dc:12}`, `onFailEffect:{type:'sealed',turns:2}`
  - 잠영술사 다수 스킬에 적용
- `handleCombatSkill`: `isSaveSkill` 분기 — `d20 + Math.floor(enemy.lv/4)` vs DC
  - 실패: `_statusEffects` 배열에 `{type, turnsLeft}` 추가, 상세 메시지 출력
  - 성공: 저항 성공 메시지 출력
- `_statusEffects` 배열: 적 유닛별 상태이상 추적

### 5. 동료 차례 누락 버그 수정
- 문제: 적 사망으로 `buildInitiativeOrder()` 재실행 시 `subTurnIdxRef` 위치 오류
- 수정: `curPart` 변수에 현재 참여자 저장 → 재빌드 후 `findIndex`로 새 위치 탐색
- 결과: 동료가 항상 이니셔티브 순서에서 정상 차례 배정

### 6. confused 상태이상 엔진 처리
- `handleEnemySubTurn` 시작부에 `_statusEffects` 순회 및 처리
- confused 발동 시 d3 판정:
  - 0 (self_attack): 자신에게 `baseAtk ± 20%` 피해
  - 1 (blood_vessel): 더 강한 자해 피해 후 상태 즉시 제거
  - 2 (friendly_fire): 다른 적 유닛에 피해 분배
- `baseAtk = cr.combat.atk` (적 생물 데이터 기준), 피해 수치는 완전 엔진 계산
- AI는 서술 텍스트만 생성 — 수치 결정권 없음

### 7. 적 수 레벨 제한 공식
- `maxTotalUnits = Math.min(9, 2 + Math.floor(level/3) + activeCompanions)`
  - Lv1, 동료 0 → 최대 2마리
  - Lv6, 동료 2 → 최대 6마리
  - 최대 9마리 절대 상한
- AI 반환 적 수가 초과 시 비율 유지 비례 축소 (`Math.round(n * max / rawTotal)`)
- 반올림 오차 보정 루프: 합산 != max 시 가장 큰 그룹에서 보정

### 8. 유닛별 HP바 실시간 업데이트
- `updateTurnStrip`: unitCursor 패턴으로 적 카드↔유닛 1:1 매핑
- 공격/피해 적용 직후 카드 `hp` 값을 `_units[idx].hp`로 갱신
- 생존 유닛이 1개라도 카드 유지, HP바 비율 실시간 반영

## 기술적 결정사항

- **ref + state 이중 관리**: React 상태(`useState`)는 렌더링용, ref는 비동기 콜백 내 최신값 보장용으로 분리
- **엔진 vs AI 역할 분리**: 수치 결정(피해·판정·상태적용)은 엔진, 서사 텍스트만 AI — AI 의존성 최소화
- **min-height:0**: flex 컨테이너 내 자식의 overflow-scroll 작동을 위한 필수 CSS 속성
- **flatDamage × level**: AI가 스킬 설명에 명시한 고정 수치를 레벨 기반으로 스케일링
