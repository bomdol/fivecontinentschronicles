01 · 프로젝트 개요

Claude API를 게임 마스터로 활용하는 AI 텍스트 어드벤처 게임. 심심풀이 개인 프로젝트이자 인공지능 활용 학습 목적. 독창적인 오리지널 세계관(판게아 분열 5대륙)을 기반으로 하며, D&D 방식 능력치 시스템과 20개국 다국어를 지원한다. 최종 배포 형태는 Capacitor.js로 패키징한 Android APK이며, 세이브 데이터는 Google Sheets에 저장한다.

03 · 현재 진행 상태
언어 선택 화면완료
  • 20개 언어 지원 (인구 1천만 이상)
  • 10개 내장 언어 (한·영·중·일·스·프·아·포·러·베)
  • 나머지 10개는 AI 런타임 번역
  • 언어별 UI 즉시 전환 미리보기
인트로 화면완료
  • 아스키 아트 + 게임 로고
  • 다국어 세계관 소개 문구
  • 페이드인 애니메이션
대륙 선택완료
  • 4대륙 (Arcania·Mechanica·Wuxia·Psychia)
  • 대륙별 특성·태그·대륙 보너스 표시
  • 5개 언어 다국어 지원
직업 선택완료
  • 대륙별 5종 (전사/마법/도적/지원/특수)
  • 특수 직업 ✦ 배지 표시
  • 직업별 능력치 미니 바 표시
  • 5개 언어 직업명·설명 번역
능력치 조정완료
  • D&D 6 능력치 (STR/DEX/CON/INT/WIS/CHA)
  • 직업 기본값: 0~100 → 8~15 스케일
  • 추가 점수 6점, ±2 조정
  • 수정치 자동 계산 표시
  • 대륙 보너스 별도 태그 표시
게임 플레이구현 중
  • Claude API 직접 연결
  • HP/상태 HUD
  • 선택지 4개 버튼
  • 자유 행동 텍스트 입력
  • 턴 기록 로그
  • Google Sheets 저장 미구현
Google Sheets 저장예정
  • OAuth 2.0 로그인
  • 대화 히스토리 JSON 저장
  • 이어하기 기능
Android 패키징예정
  • Capacitor.js WebView 래핑
  • 초기 설정 (Google 계정 + AI API 키)
  • APK 빌드 및 배포
