01 · 프로젝트 개요

다중 AI 제공자를 게임 마스터로 활용하는 AI 텍스트 어드벤처 게임. 심심풀이 개인 프로젝트이자 인공지능 활용 학습 목적. 독창적인 오리지널 세계관(판게아 분열 5대륙)을 기반으로 하며, D&D 5e 방식 능력치 시스템과 20개국 다국어를 지원한다. React + Vite 5 SPA로 구현되어 있으며, 세이브 데이터는 Firebase Auth(Google 로그인) + Firestore 클라우드 저장, 미로그인 게스트는 localStorage 폴백으로 처리한다. Capacitor.js Android APK 패키징이 완료된 상태이며, 클라이언트 전투 엔진(AC 방어 시스템, 직업별 아이템·평타)이 구현되어 있다.

08 · 기술 스택
프론트엔드
React 18 + Vite 5
컴포넌트 기반 SPA. src/screens · lore · services · data 구조. npm run build → dist/ 정적 빌드. Capacitor로 APK 패키징.
AI 엔진 — 메인
Claude API
claude-sonnet-4-20250514. 게임 마스터 역할. JSON 응답 형식. 가장 정확한 한국어 생성.
AI 엔진 — 무료
Groq (Llama 3.3 70B)
무료 API. 빠른 추론 속도. 12k TPM 제한으로 경량 시스템 프롬프트(~2,000 토큰)와 히스토리 8개 제한을 자동 적용.
AI 엔진 — 무료
Gemini 2.0 Flash
Google 무료 API. 다국어 처리 우수. 컨텍스트 창이 넓음.
AI 엔진 — 보조
GPT-4o-mini
OpenAI 보조 제공자. 사용자가 이미 키를 보유한 경우 활용.
인증
Firebase Auth
Google 로그인 원클릭. 별도 회원가입 불필요. Firestore와 통합.
클라우드 저장
Firebase Firestore
로그인 사용자 세이브 파일 클라우드 동기화. 크로스 디바이스 이어하기.
로컬 저장
localStorage
미로그인 게스트 폴백. 브라우저 재방문 시 이어하기 배너 표시.

Capacitor 8
React 웹앱 → Android APK WebView 래핑 완료. appId: com.fivecontents.chronicles. assembleDebug 성공.
